## 🔥 YAATT - Yet Another API Test Tool

_Because API testing shouldn’t feel like filing taxes._

YAATT lets you write fast, readable, no-nonsense API tests using nothing but JSON.
No GUI. No Gherkin. No 17-tab Postman workspaces.
Just pure, simple, developer-focused testing.

## 🚀 Why YAATT Exists

Modern API testing tools are bloated.

Postman? Great for clicking buttons. Terrible for writing tests.
Your test logic is buried in tabs, wrapped in scripts, and impossible to diff in a PR.

Cucumber/Gherkin? Reads nicely… until you have to maintain it. Ceremony everywhere. You spend half your life writing step definitions instead of actual tests.

**YAATT** cuts through all of that. Its just;

🟩 JSON in → 🟩 requests run → 🟩 assertions checked → 🟩 results out

No magic. No DSL. No “workspace sync failed.”

Just clean, declarative tests you can read at a glance.

## ✨ Core Features (The Good Stuff)

- JSON test files. If you can write JSON, you can write tests.
- Schema-backed. Autocomplete. Validation. Zero guesswork.
- Docker only. No Node. No Bun. No dependencies. If you have Docker, YAATT works.
- Assertions that make sense eg. `is_equal`, `is_not_empty`, and other simple operators.
- Readable diffs. Because your API tests shouldn’t look like encrypted spreadsheets.
- Fast. Launches instantly. Runs instantly.
